# 🧠 Memory Match Game

A fun and interactive **Memory Matching Game** built with HTML, CSS, Bootstrap, and Vanilla JavaScript.

Test your memory by flipping cards and matching pairs of programming language logos. The game features smooth 3D animations, interactive effects, and a victory notification powered by SweetAlert2.

## 🎮 Features

- 🃏 **16 Cards** — Match 8 pairs of programming language logos.
- 🔀 **Randomized Cards** — Cards are shuffled at the beginning of each game.
- ✨ **3D Flip Animations** — Smooth card-flipping effects.
- 💚 **Match Effects** — Matched cards remain visible with a green highlight.
- ⏳ **Mismatch Delay** — Incorrect pairs flip back after 1 second.
- 🔒 **Click Protection** — Prevents unwanted clicks during animations.
- 🏆 **Victory Alert** — SweetAlert2 notification when all pairs are matched.
- 🔄 **Replay** — Automatically restarts after the victory notification.
- 📱 **Responsive Design** — Adapts to different screen sizes.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/vugarjs/MemoryMatch.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser or use the VS Code Live Server extension.

No installation or build process is required.

## 🎯 How to Play

1. Click a card to reveal its programming language logo.
2. Click another card to find its matching pair.
3. If the cards match, they remain visible.
4. If they don't match, both cards flip back after 1 second.
5. Find all 8 pairs to win the game!
